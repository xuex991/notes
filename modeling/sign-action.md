# Sign Action 模型

## Project

```text
Sign Action = Build + Operate
```

## Build

```text
Build = Model + Frontend
Build → Product
```

## Operate

```text
Operate = Channel → Exposure → Click → Use → Result → Payment
Operate → Paying User
```

## Goal

```text
Project Success = Product + Paying User
```

## Current

```text
Current = Build → Model
```

Model 中已经确定的部分：

```text
Job = Config + Worker
Config = Context + Trigger + Policy
Context = Input + Output
Worker(Context) → Result
```
